# Архитектура проекта RuBin

## Структура директорий
- 'server/' - серверная часть (Node. js + Express), маршруты API, база sQLite и модуль
модерации.
- 'public/* - клиентская часть сайта (HTML, стили css, клиентские скрипты Js, загруженные
изображения).
- 'tests/' - автоматические тесты модуля модерации и API.
- 'docs/* - проектная и тестовая документация.

## Логика работы модерации при загрузке пина
1. Пользователь отправляет изображение, заголовок, описание и теги.
2. Модуль *moderationService нормализует текст и сверяет его со словарями.
3. Статусы пина: approved (публикуется сразу), *pending (отправляется модератору),
'rejected (блокируется сразу).
