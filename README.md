# RuBin — Российская платформа визуального вдохновения

**RuBin** — веб-сервис для обмена фотографиями, идеями и эстетикой (отечественный аналог Pinterest) с встроенной системой фильтрации и модерации контента в соответствии с законодательством РФ и традиционными духовно-нравственными ценностями.

## Команда проекта
- **Егор** — Team Lead & Frontend-разработчик (управление проектом, UI/UX, клиентская часть)
- **Лев** — Архитектор & Backend-разработчик (проектирование БД, серверное API, ядро модерации)
- **Елисей** — QA-инженер (разработка правил фильтрации, тест-кейсы, автотестирование)

## Стек технологий
- **Frontend:** HTML5, CSS3 (Masonry Grid), Vanilla JavaScript
- **Backend:** Node.js, Express
- **База данных:** SQLite
- **Модерация:** Многоуровневый словарный фильтр + панель ручной модерации
